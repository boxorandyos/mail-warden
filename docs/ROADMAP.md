# Mail Warden Roadmap

## MVP (Phase 1)

- Postfix + Rspamd + ClamAV integration points
- Inbound and outbound mail flow contracts
- Policy engine with hard gates and bounded signal caps
- IP/sender/domain reputation primitives
- Recipient validity + velocity + relationship learning
- LDAP authentication for quarantine portal
- Structured security and audit events

## Phase 2

- Entra authentication and directory sync
- ASN/infrastructure reputation expansion
- Directory enumeration detection refinement
- Outbound account-compromise heuristics
- Policy classes by mailbox profile

## Phase 3

- BEC-focused anomaly detection
- DLP module options
- Attachment sandbox integrations
- Campaign clustering and fuzzy/correlation analysis
- High availability active/passive deployment model

## Phase 4

- SIEM/Sentinel integrations
- Incident-response automation hooks
- Multi-organization threat sharing models
